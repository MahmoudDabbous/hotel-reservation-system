# Hotel Reservation System

This is a Spring Boot-based Hotel Reservation System that allows users to manage rooms, guests, and reservations. The application provides both a web interface and RESTful APIs for interacting with the system.

## Features

- **Room Management**: View and manage hotel rooms, including room details such as name, number, and bed information.
- **Guest Management**: Manage guest information, including personal details like name, email, and phone number.
- **Reservation Management**: Create, update, and delete reservations for specific rooms and guests.
- **Occupancy View**: View room occupancy for a specific date, including guest details or vacant status.
- **RESTful APIs**: Expose APIs for rooms, guests, and reservations for external integrations.

## Technologies Used

- **Spring Boot**: Backend framework for building the application.
- **Thymeleaf**: Template engine for rendering dynamic HTML pages.
- **PostgreSQL**: Database for storing application data.
- **Lombok**: Simplifies Java code by reducing boilerplate.
- **Bootstrap**: Frontend framework for responsive design.

## Prerequisites

- Java 21 or higher
- Maven
- PostgreSQL
